# 晶血龙兽 V12 重制版

2026-10-02 整合说明：下面的实机结果与世界对象是 2026-09-09 的历史交付记录。本轮仅准备未发布的源代码候选，未重新安装或登录该世界；当前生成器采用 master 的独立状态 ID，旧接受 JSON 的哈希和旧 `dazed` 结果不改写为新版产物的运行时接受。正式 Actor 必须重新走 CLI 与来源验证，不能用旧 JSON 覆盖新输出。

适用版本：Foundry **12.331**、dnd5e **4.3.9**。已在用户指定世界导入并完成下列战斗机制的实测。

## 在当前世界使用

1. 在角色目录打开 **晶血龙兽·重制验收 0909-1932** 文件夹，使用其中的 **晶血龙兽 (Crystalbleed Drakon)**。原地图上的旧龙兽保留原样，使用新版时请从这个文件夹拖入新指示物。
2. 同目录的 **月石晶体 (Moonstone Crystal)** 是召唤模板。保留唯一一份同名模板；齐射会自动从它生成晶体。
3. 每次进入或刷新游戏后，由 **一个 GM 客户端**运行宏目录里的 **晶血龙兽·战斗控制**。本次交付结束时它已启用。保持该 GM 客户端查看战斗所在场景。
4. 选中新版龙兽、标选目标后，可以点击面板上的晶片齐射，也可以用控制宏的同名按钮。宏会结算豁免、扣血、恍惚、半血腐化、相邻召唤和先攻。
5. 晶体的回合开始时自动戳刺；不要额外重复点击。重复点击会被同回合保护阻止。关闭控制窗口不停止自动处理；刷新页面会停止，需重新运行宏。

“验收靶（测试专用）”子目录和“晶血龙兽·验证场 0909-1932”场景用于保留测试证据，不是参战所需内容。该测试战斗已回到未开始状态。

## 本版规则

| 能力 | 最终行为 |
|---|---|
| 原有攻击 | 保留面板实际数值：全部命中 +11；啃咬 3d10+6 穿刺＋2d8 心灵，爪击 3d8+6 挥砍＋1d8 心灵，尾击 4d6+6 钝击＋1d6 心灵 |
| 月蚀守护 | 一次伤害结算合计超过 20 才减半，向下取整；20 及以下不减免。不同伤害类型在同次结算中合计判断。正常“应用伤害”按钮和宏伤害结算都会经过该计算；直接手改 HP 不触发 |
| 绯晶拒绝 | 每日两次，将豁免失败改为成功；守护碎裂至龙兽下一回合开始。碎裂时无减伤，AC 不变；次数耗尽后恢复为超过 20 点只减少熟练加值（5） |
| 腐化 | DC 18 魅力，首次失败只添加腐化标记；已腐化者再次失败才增加一级力竭。“绯晶腐化”和“月石腐化”为同一状态 |
| 噩梦吐息 | 60 尺锥形，DC 18 感知，6d10 力场；失败恐慌 1 分钟，成功半伤且无恐慌；回合结束重复豁免，成功解除。充能 5–6 |
| 晶片齐射 | 消耗 2 传奇动作，30 尺内可见单体，DC 18 体质；失败 2d8 心灵＋恍惚，成功半伤且无恍惚。恍惚持续至目标下一个回合结束。龙兽半血及以下时，失败目标追加腐化豁免；无论初始豁免成功或失败都召唤晶体 |
| 月石晶体 | 中型构装体，AC 17，HP 15，所有速度 0，不能移动；生成在齐射目标旁边空位，立即投掷先攻并加入战斗，生成瞬间不戳刺 |
| 月石戳刺 | 到晶体自己的回合，对十尺内所有其他生物（不分敌友）进行 DC 18 敏捷豁免；失败受到 2d6 穿刺，再进行独立 DC 18 魅力腐化豁免；成功则不受伤害，也不触发腐化。每回合一次，HP 0 不行动 |

腐化和吐息的 DC 18 参照锁定 dnd5e 4.3.9 官方成年绿龙的毒素吐息，只借用 DC，不改变本生物的豁免属性或伤害类型。恍惚使用当前世界已有的 `dazed` 状态，并尊重目标状态免疫；不会替换为震慑或麻痹。

## 仍由 GM 操作的部分

- 吐息锥形朝向和目标选择：先标选合法六十尺锥形内目标，再使用吐息。宏不会替你判断朝向。
- 普通攻击仍用原生面板掷骰，并照这个世界现有流程应用伤害。多重攻击为一次啃咬和两次爪击；传奇尾击调用普通尾击。必要时由 GM 选择不同目标。
- 尾击推退/扫倒的二选一、具体推离路径、血液支配的反应攻击及目标选择、掠流滑翔的移动由 GM 操作。缺失的尾击扫倒条目已根据原尾击描述补齐，DC 与推退同为 19。
- 盟友拔刺救援保留原规则：五尺内盟友使用一个动作，DC 15 运动或医药成功后，停用目标的噩梦吐息恐慌效果。
- 对宏内部的豁免，目标若是新版龙兽且能用绯晶拒绝，宏会在后果发生前询问 GM。对普通法术/其他原生掷骰，请在应用失败后果前使用绯晶拒绝；它不会倒推撤回已经手工应用的伤害。
- 腐化的长期移除仍按战役规则由 GM 决定。没有修改整个世界的 Midi 自动豁免、自动扣血或 OnUse 宏设置。
- 专用宏由 GM 代目标进行暗骰豁免并应用伤害；玩家临时反应、临时加值与复杂反应链仍须 GM 裁定，这些跨玩家交互未纳入本次验收。

## 文件与来源

- `dragon.json`、`crystal.json` 均由项目正式 CLI 从包内 Markdown 生成，未手工修补 Actor JSON。
