# 晶血龙兽 V12 交付辅助

## 范围

此目录只构建本次生物的独立战斗宏，不是通用 Foundry 安装器。Actor 定义必须继续来自正式 CLI 的两个 Markdown 来源；本目录不得生成或修补 Actor/Item 基础数据。

宏绑定来源中明确的 behaviorMechanics ID，只处理带这些标记的新生物。不得按同名自动接管用户原有龙兽，不改全局设置，不安装模块，不重启服务器。

## 验证

测试只使用本任务新建的场景、Actor、Token 和战斗。自动腐化、扣血和移动必须先通过纯逻辑检查，再在授权 V12 世界验证。对宏生成物和原生导入产物分别记录哈希与验证结果。
