# 效果制作与自审

## 风格基准

权威来源为模块的 `docs/asset-provenance.md` 和 `docs/default-art-integration-2026-09-09.md`。需要某种基准时再打开对应原图或实机截图，无需每次查看全部素材。

| 已确认基准 | 复用的判断 | 当前实现例子，不能套给所有新效果 |
| --- | --- | --- |
| 火焰 | 亮芯、橙色火体、稳定主形，动态不能把形状冲成泛光雾 | A/B/C三图；原生Torch速度10、幅度8、alpha0.25，两逻辑阶段共用视觉 |
| 冰霜 | 早期附着与成熟材质有明确差异，保留有意设计的薄层 | I为20%冰面下垫+霜粒，II为冰面；反光速度3 |
| 荆棘 | 灰褐低饱和，自然分叉和留白，密度表达阻挡而非金色大刺 | 已确认两阶段PNG；35%视觉外扩；I迟滞、II移动边界墙 |

## 逐项视觉判断

每项写短结论和证据位置，不用平均分掩盖失败项。

- **身份与阶段**：目标看起来是否是所需材质；迟滞、阻挡等重要行为是否有相应视觉提示。
- **地图协调**：在相近底图、尺寸和照明下比较；色彩和亮度是否抢过 Token、地形边界及重要地图信息。实心冰、岩石等可以遮地，不能强制所有效果同一透明率。
- **形态**：单格边缘是否自然；是否有明显裁断、假棋盘、黑底、碎线、悬空残片、规则挖洞或无意义重复的小圈。
- **连片**：正常缩放检查重复、相交处过亮、外扩与逻辑格偏差；孔洞中心是否仍露地。允许诚实记录可见重复，不宣称未经证明的无缝或拓扑连接。
- **动态**：主形稳定、循环无突跳、没有闪烁白块或过强全局漂移。播放截图序列或实际录像，不以一张静态图判定。
- **操作后**：阶段拆分、擦除、撤销重做后，相邻格的外观是否稳定，双层素材是否成对处理。

## 素材证据

`inspect_asset.py` 需要Python与Pillow，只读取明确传入的素材并输出JSON。例如在Skill目录执行：

```powershell
python scripts/inspect_asset.py path/to/terrain.png --require-transparent
python scripts/inspect_asset.py path/to/approved.png --expected-sha256 FULL_SHA256
```

报告只证明文件层，不证明没有绘制出的棋盘格、画面好看、或规则正确。alpha覆盖率不是藤蔓数量，也不能代表视觉质量。来源要求保留原图时核对全文件哈希；重绘后必须明确记为新候选。

过去ImageGen编辑曾多次输出RGB假棋盘。发现后不要再次把同一“去棋盘”请求当可靠修复：可根据授权和目标重新生成，或选择确实可用的局部编辑方式；仍要检查真实alpha和实际边缘。按亮度抠除内层会留下碎枝，整块抠除会形成假洞，均不得冒充自然减量。工具和权限约束仍适用。

## 最小实机证据

- 精确Foundry/dnd5e版本、运行目录、当前场景和安装哈希。
- 使用正式画笔产生最终文档；独立临时Tile演示只能证明美术样板，不能替代模块集成。
- 检查纹理实际加载、alpha/tint/层次、格位/阶段、相应灯光与墙。Foundry可能把分数尺寸整数化，记录实际值。
- 若改变Tile或格位行为，覆盖方格及支持的六角格；图层采用矩形Hex兼容时明确说明，不能以方格结果代替Hex。
- 用真实Token的原生地形路径验证移动消耗/阻挡。路径测量不等于实际玩家拖拽；需要独立玩家证据时用独立会话验证。
- 清除保留非模块文档；恢复原view、active、暂停状态，清理拥有标记的临时对象和本次进程。生产及持续运行权限仍按项目规则，不从历史测试时长推导授权。
- 需要性能结论时做同镜头、同客户端、相同可见/聚焦状态的适量比较；后台标签rAF/FPS、一次读值和工具超时不能单独证明性能或根因。常规素材变更不自动安排长时压力测试。

## 本地版本与工具注意

- Foundry14.364的场景背景位于Level；不要在旧Scene.background兼容入口上反复写入再以灰底截图验收。
- 地形几何沿用当前模块；不要猜Token坐标、Tile锚点、Hex邻接或相应API的版本语义。
- 浏览器截图出现陈旧画面或错误尺寸时，先核对DOM/画布状态和当前工具文档。只使用支持的浏览器接口恢复并重拍，不把工具返回图当作必然最新。
- 不把报告中的旧“PASS”用于新图片、新代码或其他实例；保留旧兼容层诊断与新路径错误的区别。

## 自审与升级询问

常规审美、素材变体、原生参数小调与本地修复由代理判断。只有缺失信息会实质改变玩法/范围，或触及尚未授权的生产、发布、不可逆数据操作时询问；先完成不依赖该答案的部分。默认自审通过后继续授权的本地接入，最后展示结果；不要再在每张图、每个速度档之间追加人工审核门槛。
