# FVTT 工具合集 · 统一操作手册 0.3.0

这是 Foundry VTT 14.368 的 GM 只读手册本地交付候选。模块 ZIP 内置用户条目投影；交付目录中的独立 `工具手册.html` 保留完整目录，可离线打开。两者的正文、搜索和样式都随各自文件提供，不需要在线服务。

## 离线阅读

直接打开交付目录中的独立 `工具手册.html`。它不在模块 ZIP 内，是单个自包含文件，不需要启动 Foundry，也不需要连接网络。可使用目录、搜索和条目链接阅读完整工具手册。

## 在 Foundry 中使用

1. 在自己的 Foundry VTT 14.368 数据目录下，把 ZIP 解压为 `Data/modules/fvtt-suite-console/`，确保该目录直接包含 `module.json`、`scripts/` 和 `styles/`。操作前请核对目标目录；若已有同名模块，先按该环境的维护流程处理，不直接覆盖。
2. 在世界的模块管理界面启用“FVTT 工具合集 · 统一操作手册”，按 Foundry 提示重载页面。
3. 以 GM 身份进入 **游戏设置 → 配置设置 → 模组设置 → 统一操作手册 → 打开手册**。可按用途浏览或搜索；“刷新状态”会重读当前客户端看到的工具安装和启用状态。

此模块只提供阅读、搜索、复制文本和只读状态展示。复制的命令不会自动运行。条目中提到的其他工具仍须独立安装和启用，显示版本不表示其功能已经通过当前世界验收。模块帮助 API 的版本保持 1。

## 校验交付文件

同目录的 `SHA256SUMS.txt` 记录 ZIP、独立 manifest 与独立 HTML 的 SHA-256。`release-candidate.json` 列出 ZIP 内允许的每个文件、字节数和 SHA-256，以及 ZIP 总大小和独立 HTML 的源/交付身份。独立 manifest 与 ZIP 内 `module.json` 应逐字节相同。发布渠道、规范下载地址、正式品牌和授权尚未确定；这份候选不声明公开发行可用。
