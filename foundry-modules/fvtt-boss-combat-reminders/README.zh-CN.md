# Boss 战提醒 Boss Combat Reminders

独立的 Foundry 模组，用可点选的私密卡片提醒活动 GM 处理怪物的传奇动作、传奇抗力、巢穴动作、死亡和浴血相关能力。

## 本地试用

目标为 Foundry Core 14.370 与 dnd5e 6.1.1。可在测试世界的模块管理中启用本模组。Monk’s、Midi-QOL、DAE 和 Chris Premades／CAT 均为可选兼容。

- 参加战斗且具有原生传奇活动的 NPC 会被自动识别。到合规时机时，同一回合结束只弹一张包含各 Boss 的传奇动作卡。
- 传奇抗力使用 dnd5e 的失败豁免消息和原生扣次、改判操作。
- 打开怪物卡的「在巢穴」设置后，其原生巢穴活动在先攻 20 提醒，先攻 20 的普通回合先行。
- 在怪物卡顶部菜单打开「Boss 战提醒」。这里可以禁用该怪的提醒，或指定归零、死亡及浴血能力的时机。明确的活动条件及描述中的常见中英文触发语句可以自动识别。其余用法可在备团时手动指定。
- 有归零或死亡能力的参战怪物归零后，GM 先处理归零能力。若裁定存活，把 HP 恢复到大于 0，待结算自动解除。若确认死亡，再处理死亡能力。能用的 Activity 走原生使用；只有描述的能力会打开物品供裁定。
- 等模板、豁免和伤害处理完毕，再点「处理完毕」，或点「跳过并收尾」。这时才标记死亡与战败，已启用的 Monk’s 可按自身设置隐藏、淡出和绘制血迹。关窗口和推进回合后仍可用 Token 工具栏的骷髅按钮重开待结算。结束战斗前会提示仍待处理的怪物。
- 在提醒中按怪物头像找到对应的动作，点选整行使用。传奇动作显示怪物的剩余点数及每个动作消耗。标题旁可跳过这张提醒，也可继续推进回合。实际使用沿用原生记录。
- 动作名下方可显示 dnd5e 活动里的射程、区域、目标类型与数量和持续时间，采用系统当前语言。只有能力正文的条目需要打开原生物品查看。
- 即时、回合开始和持续能力，以及浴血强化攻击，都读取怪物当前的浴血标记。黑布丁刚获得标记时提示分裂。黏土魔像轮到自己且仍有标记时，每回合提示一次失心狂怒。狂战士每次浴血期间可从卡片应用一次原生优势，浴血结束或 HP 归零时自动移除本模组添加的效果。
- 怪物当时没有浴血标记，且从浴血阈值以上直接降到 0 HP 时，符合「陷入浴血，归零也触发」或「首次陷入浴血，归零也触发」的能力会加入归零待结算卡。

- 「Boss 战提醒」设置可为单只怪物填写浴血阈值，留空时用系统默认。GM 也可点「强制浴血」或「恢复自动」。世界关闭自动标记时，怪物跌到阈值可从提醒卡点击「标记浴血」，回血超过阈值后撤掉卡片添加的标记。
- 在攻击正文里写「当浴血时，命中时……」或写明浴血影响触及、射程和目标。首次进入浴血时可看到受影响的招式。选目标前在角色卡查看范围变化，结算时在原攻击卡查看当前适用的命中规则。强化说明和按钮只显示给 GM。
- 在「浴血攻击配置」选择普通攻击对应的浴血 Activity，以及可选的命中后 Activity 或物品效果。有效命中可直接结算，信息不足时在攻击卡上确认目标。只有正文的效果由 GM 根据提示处理。

`bun run build:boss-combat-reminders` 生成本地安装目录和 ZIP。使用 `bun run test:boss-combat-reminders` 运行模块行为检查。版本准入、构建、原生运行时验收和后续兼容各有自己的状态。

第三方适配按已核对的版本启用。Midi-QOL 和 Combat Details 的目标保护，以及 DAE 的归零到期延后只作用于待结算怪物。DAE 范围为 Midi 的归零到期中明确删除该 Token 的效果。已识别的 CPR `useOnDeath` 可从卡片点选。GM 完成或跳过后，该绑定不再重复触发。自行编写的退场宏和其他动画绑定按具体配置核对。
