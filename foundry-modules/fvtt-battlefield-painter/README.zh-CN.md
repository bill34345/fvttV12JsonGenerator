# Battlefield Painter · 0.3.0-alpha.2

这是GM使用的战场地形画笔。当前目录包含42个选项：36个地形配置和6个月蚀矿图案，支持阶段、部分颜色与光照、可选环境音，以及按网格绘制、擦除和历史恢复。当前进度与实际接受范围见[接续入口](docs/CONTINUATION.md)。

## 版本与接受范围

运行代码精确放行Foundry14.364/dnd5e5.3.3、Mirror14.368/5.3.3，以及既有Next14.368/6.0.2或6.0.5；其它配对失败关闭。manifest范围声明不代表所有组合和地形已接受。14.364的代表样本有真实三格型证据；既有Next接受只覆盖其报告里的Square Fire切片。Mirror14.368/5.3.3已取得本轮三格型代表交互、GM/SY实际移动、HexCols26basic/36阶段与音源技术生命周期证据，具体范围见[本轮技术验收](docs/completion-2026-10-05.md)。

素材为本项目原创或按明确许可制作，用户已确认的火焰、冰霜、荆棘及后续图案按来源记录保留。原版Tile Arsenal在本地作为独立模块安装和比较，文件不并入本模块。

## 使用

1. 以GM身份进入支持的世界并查看一个有网格的场景，在Tiles控制组点击火焰图标“战场地形画笔”。
2. 选择地形及其已有阶段。各配置有1至4阶段；单阶段配置不提供阶段升级。
3. 支持换色的13类地形提供原色加12色：火焰、薄雾、毒雾、雷电区域、魔法阵、魔法光、传送门、四种符文、组合符文与浓烟。灯光随颜色调整，颜色和素材选择存入地形文档。
4. 选择绘制、擦除或切换阶段，以及自由、直线、填充形状和0至4格半径。填充使用拖动两端的网格范围。
5. 启用画笔后按住左键拖动，松开提交整笔。擦除只处理模块拥有的格位；切换阶段保留未命中的格位。撤销/重做会核对当前笔画，发现外部修改时拒绝覆盖。
6. 需要沿Region铺设时先选中Region，再点击面板入口或Shift+P。按格心判断覆盖，处理孔洞及重叠去重。
7. 按住Shift选择地形会收起面板，落笔完成后恢复。清除本场景地形时先核数量预览，再明确确认。

## 视觉与玩法

火焰、冰霜、荆棘及其它地表使用已确认的原生Tile素材；火焰、冰霜和酸液等依配置生成原生光源。冰霜按薄霜/冰面分层，酸液与熔融熔岩有轻微内部流动。旧独立Fire/Frost标记仍有兼容渲染，新增火焰采用原生素材；它们的性能和画面证据分别记录。

荆棘界面顺序为疏根、密枝、棘墙，原来的存储索引保持。疏根正常移动；密枝与棘墙消耗翻倍，棘墙只阻挡移动。现有荆棘规则对飞行也增加成本，未宣称与原版完全相同。碎石、碎木、地裂、油脂、沙地和地刺只增加步行成本；力场阻挡外周移动，石柱阻挡移动与视线。其它配置按面板说明使用，伤害、滑倒、坠落、传送、治疗和法术由GM裁定。

蛛网及整张类图案每笔一张，随范围放大，擦除固定原图框并裁去格位。血迹、碎石、碎木等在新绘制时选取变体，之后刷新与历史保持选图。六个月蚀矿选项固定使用所选图形，作为静态场景覆盖物，不自动腐化或伤害。

## 环境音

环境音默认关闭，只影响接下来绘制的笔画。9类地形使用7个声音源：火焰、熔岩、酸液、能量、圣光、法阵与邪光。能量沿用已认可的5.24秒原文件，其余6条为约180秒立体声环境音；火焰/熔岩、圣光/法阵分别使用独立声音。每笔一个原生AmbientSound，范围覆盖笔画；随阶段、擦除和历史保存或清理。已放置声音可在声音图层调整或静音。

用户选择按原版方向重做自有声音。V3替换其它声音并调整新笔画起始音量：火焰0.8、酸液0.26/0.4、圣光0.3、邪光0.7、熔岩0.8、法阵0.25；能量三类仍0.1。机械解码、接缝与原能量hash通过不代表听感接受，V3的技术实机与主观试听状态见[接入记录](docs/audio-v3-integration-2026-10-04.md)。素材许可见[声音署名](assets/audio/ATTRIBUTION.md)。旧白噪声继续退役；旧场景数据不自动迁移，既有四个相同文件路径的音频内容随模块更新，已放置文档的音量仍保留原值。

## 安装与检查

在模块目录运行`bun run test:coverage`、`bun run typecheck`和`bun run build`。构建产生完整module目录和ZIP；机械通过不等于真实画布、玩家端或声音接受。

本地安装器只接受批准的Mirror路径。`bun run install:local`预览，`bun run install:local -- --apply`只安装到不存在的目标；已有目录会被拒绝。已有共享安装的升级按[本轮维护记录](../../docs/reviews/2026-10-03-foundry-14-365-mirror-upgrade-and-tile-arsenal.md)及Foundry Ops门禁处理，需核服务、实际代码和文件hash。测试结束恢复本轮对象/设置/场景并保留常驻服务。
