# Ambience sources and changes

The six V3 ambience files are independent 180-second stereo Vorbis mixes, prepared on 2026-10-04. Artistic listening acceptance remains separate from source permission, decoding and runtime checks. No Tile Arsenal audio bytes or derived recordings are included.

| Files | Sources and selected permission | Changes |
| --- | --- | --- |
| `fire-loop.ogg`, `lava-loop.ogg` | **Fireplace Sound loop**, PagDev, [source](https://opengameart.org/content/fireplace-sound-loop), [CC0](https://creativecommons.org/publicdomain/zero/1.0/); **Spell 4 (fire)**, Bart K., [source](https://opengameart.org/content/spell-4-fire), [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/) | Filtering, softened transients, speed/pan variation, irregular overlap, level adjustment and stereo loop crossfades. Fire has a broad fireplace/gust body; Lava is a separate low rumble composition. |
| `acid-loop.ogg` | **Bubbling Acid**, spookymodem, [source](https://opengameart.org/content/bubbling-acid), [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/) | Extracted 57 irregular bubble events over three minutes, quieter filtered corrosion layer, pan/speed variation and crossfades. |
| `chime-loop.ogg`, `drone-loop.ogg`, `magic-circle-loop.ogg` | **4 Atmospheric ghostly loops**, Independent.nu, submitted by qubodup, [source](https://opengameart.org/content/4-atmospheric-ghostly-loops), [CC0](https://creativecommons.org/publicdomain/zero/1.0/) | Diffuse ambience mixes with filtering, speed/pan variation and crossfades. Holy and Magic Circle include quiet derived accents from the approved Energy source below. Legacy chime/drone filenames preserve existing references; V3 replaces the previous project additive synthesis. The source page does not establish microphone-recording provenance. |
| `energy-loop.ogg` | **Seamless Energy Emission Loop**, zeroisnotnull, [source](https://opengameart.org/content/seamless-energy-emission-loop), [CC0](https://creativecommons.org/publicdomain/zero/1.0/) | Approved original OGG bytes remain unchanged: SHA-256 `a7502a3940ca3f1d0cafb81acd9cc6498c551ac5e2553bbede8c8896468b1439`. Force Barrier, Lightning Field and Portal retain this source. |

The fire-spell page offers several licenses; this project selects CC BY 3.0. Both CC BY credits and these indications of changes must accompany the derived files. No source author endorses this module.

Nine configurations use seven sound sources. Ambience is opt-in, one owned AmbientSound per stroke. Rift and Wild Magic remain excluded. Source hashes, generation method and validation boundary are recorded in `scripts/generate-parity-audio.py` and [the V3 integration record](../../docs/audio-v3-integration-2026-10-04.md).
