# 唤焰祭司与召唤红龙

> 这是一份普通人可以直接阅读、修改的生物资料示例，展示“一份MD写两种生物及其召唤关系”。两种生物均为自制演示数据；红龙不采用某个官方年龄阶段的数据，挑战等级未做平衡验收。
> 本例用于 Forge 0.3.0 候选的原始MD战斗包入口。该红龙示例尚未进行真实模型和战斗验收，不能把晶血龙兽的验收结果当作本例已通过。

## 生成内容

这份资料包含两个独立生物：**唤焰祭司**和**召唤红龙**。请分别建立它们的数据卡。

唤焰祭司具有“召唤红龙”动作。使用这个动作时，在场景中生成下文定义的召唤红龙。红龙具有独立生命值、先攻和行动，不是祭司的临时变身，也不是只有文字说明的效果。

角色目录中只需要一个唤焰祭司条目和一个召唤红龙条目。每次实际召唤都从红龙条目生成独立指示物；每只红龙分别记录生命值和状态，不修改其他红龙或角色目录中的原始数据。

## 生物一：唤焰祭司

中型类人生物，人类，守序邪恶。

- 护甲等级：15，仪式护甲。
- 生命值：65，生命骰10d8+20。使用固定生命上限65，不随机掷生命值。
- 速度：步行30尺。
- 力量10、敏捷14、体质14、智力12、感知16、魅力12。
- 豁免：感知+6，魅力+4。其他豁免仅使用对应属性调整值。
- 技能：宗教+4，察觉+6。
- 伤害抗性：火焰。
- 伤害免疫、伤害易伤、状态免疫：无。
- 感官：普通视觉，被动察觉16。
- 语言：通用语、龙语。
- 挑战等级：5，经验值1800，熟练加值+3。
- 先攻：+2。

### 特性

**火焰仪式。** 祭司可在手中产生火星，用于点燃接触到的蜡烛、火把或篝火。此特性不造成战斗伤害，不提供额外光照范围或数值加成。

### 动作

**仪式短杖。** 近战武器攻击，命中+3，触及5尺，一个目标。命中造成1d6钝击伤害。

**灼热火矢。** 远程法术攻击，命中+6，射程60尺，一个目标。命中造成2d8火焰伤害。此动作没有每日次数限制。

**召唤红龙（每日一次）。** 祭司使用一个动作，在自己能够看见且位于30尺内的一处未占据空间，召唤一只下文定义的召唤红龙。此能力不进行攻击检定或豁免，不额外造成伤害。

具体规则如下：

- 由GM选择召唤位置。红龙为大型生物，所选位置必须容纳10尺见方的空间，并且没有其他指示物或墙体阻挡。先检查合法位置，再消耗次数；没有合法位置时取消这次使用，不消耗每日次数。
- 红龙对祭司及其盟友友好，敌对关系由GM按当前遭遇确定。由GM控制红龙，祭司指挥它不需要额外动作。
- 战斗中使用时，红龙独立投掷1d20+1先攻，加入祭司所在的同一场战斗。若祭司没有唯一可确定的当前战斗，由GM选择；没有选定前不消耗次数或生成红龙。
- 红龙生成时不立即行动。若本轮尚未经过它的先攻时点，则在该时点首次行动；若本轮已经经过或正处在该时点，则从下一轮自己的回合开始行动。
- 非战斗中使用时，只生成红龙，不自动建立战斗。之后进入战斗时，由GM把它加入战斗并投掷先攻。
- 红龙持续存在1分钟，以游戏内时间计算，不使用现实时间。在战斗中，按每轮6秒推进这段时间；切换或结束战斗不重新开始计时。
- 此能力不需要专注。每位祭司最多同时维持一只召唤红龙；已有存活且未消失的红龙时不能再次使用此能力，也不消耗次数。
- 红龙生命值降至0、持续时间结束，或召唤它的祭司生命值降至0、死亡、陷入昏迷时，红龙消失。移除这只红龙的场景指示物及对应战斗成员，保留角色目录中的召唤红龙条目。
- 同一场景中不同祭司各自召唤的红龙分别绑定各自的召唤者；一名祭司倒下不会移除其他祭司的红龙。
- 每日使用次数在该祭司完成长休时恢复为一次；红龙提前消失不返还次数。

### 附赠动作、反应与传奇动作

无专属附赠动作、反应或传奇动作。

## 生物二：召唤红龙

大型龙，守序邪恶。它是本示例完整定义的自制召唤生物，其数据如下，不自动套用其他红龙的数据。

- 护甲等级：17，天生护甲。
- 生命值：85，生命骰10d10+30。每次召唤均以固定生命上限85、当前生命值85出现，不随机掷生命值。
- 速度：步行30尺，飞行60尺；不能悬停。没有游泳、攀爬或掘穴速度。
- 力量18、敏捷12、体质16、智力10、感知12、魅力14。
- 豁免：敏捷+4，体质+6。其他豁免仅使用对应属性调整值。
- 技能：察觉+4。
- 伤害免疫：火焰。
- 伤害抗性、伤害易伤、状态免疫：无。
- 感官：黑暗视觉60尺，被动察觉14。
- 语言：理解并能说通用语和龙语。
- 挑战等级：5，经验值1800，熟练加值+3。击败召唤物是否奖励经验由GM决定。
- 先攻：+1。

### 特性

**召唤联系。** 红龙遵循召唤它的唤焰祭司的指令，其持续时间和消失条件使用上文“召唤红龙”的规则。它不与祭司共享生命值、状态、行动或其他资源。

### 动作

**多重攻击。** 红龙进行一次啃咬和一次爪击。这两次攻击可以选择不同的合法目标，分别结算命中和伤害。多重攻击不能替换成火焰吐息。

**啃咬。** 近战武器攻击，命中+7，触及10尺，一个目标。命中造成2d10+4穿刺伤害，外加1d6火焰伤害。未命中时不造成伤害。

**爪击。** 近战武器攻击，命中+7，触及5尺，一个目标。命中造成2d6+4挥砍伤害。未命中时不造成伤害。

**火焰吐息（充能5–6）。** 红龙使用一个动作，向自己选择的方向喷出30尺锥形火焰。区域内所有生物，包括盟友和召唤者，分别进行DC14敏捷豁免。失败受到4d6火焰伤害，成功受到一半伤害，向下取整；无额外状态。

火焰吐息在红龙刚被召唤时可用。使用后进入未充能状态；此后每次红龙自己的回合开始时投掷1d6，结果为5或6则恢复可用，其他结果不恢复。恢复充能不等于立即发动吐息，仍由GM在红龙回合选择是否花费动作使用。

### 附赠动作、反应与传奇动作

无专属附赠动作、反应或传奇动作。

## 自动处理与GM操作

我希望自动处理召唤次数、根据GM选择的合法位置生成红龙、保存召唤关系、战斗中掷先攻并加入战斗、记录持续时间，以及满足消失条件后的清理。

红龙不会自动决定战术，不会在出现时自动攻击。由GM选择它每回合的目标、移动、多重攻击或吐息；吐息范围内包含哪些生物也由GM确认。确定目标后，按能力文字结算攻击、豁免与伤害。

如果某条自动处理规则还不能实现，请明确列出需要GM手工操作的步骤，不要把它写成已经能够自动执行。
