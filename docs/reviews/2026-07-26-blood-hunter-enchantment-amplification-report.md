# 血猎手附魔与血咒增幅改造报告

> 历史报告：2026-07-26 的实际运行时测试已经推翻本报告的功能性结论。当前证据请以 `2026-07-26-blood-hunter-complete-runtime-repair-report.md` 和 `BH-ACT-003` 为准。

## 结论

本轮代码与生成物已经完成，边界是“可导入的 homebrew 数据 + 本地锁定版本的结构/语义验证”。没有修改卡勒姆、世界合集、生产服务器或线上数据。

- 当前锁定：Foundry 14.364、dnd5e 5.3.3、MIDI-QOL 14.0.11、DAE 14.0.12。
- Item Macro 3.0.1 仅记录为可选后备；其 manifest 只声明验证到 Foundry 13，本轮没有把它作为 v14 必需依赖。
- `猩红仪式`和`鲜血秘法`本体均没有 Activity。
- 七种血仪均包含 Enchant Activity、一次触发的激活失血和对应武器附魔效果。
- 实际源数据包含十四种而不是十三种可选血咒；十四种全部具有普通、增幅、增幅失血三个 Activity。弑灵、突变、渎魂的三个同名子职血咒也采用相同三段结构。

## 自动化边界

- 血仪附魔使用 dnd5e 原生 Enchant；额外伤害写入武器的全部 attack Activities。
- 激活/增幅失血使用 Utility 掷骰加 Activity Macro 直接降低当前 HP，因此不经过抗性、免疫或临时生命值，也不会被 MIDI 当作普通伤害重复应用。
- 每次休息后的首次增幅会设置等量临时生命值和 `shortRest` 标记；MIDI 14.0.11 的休息管理器会在短休和长休时清除该标记。
- 焦虑、捆缚、胀痛、腐蚀、怒号、乱心和鲁莽只自动施加本地锁定字段能够可靠表达的状态或数值。
- 胀痛反噬、驱魔控制者、暴露伤害类型、盲目后续攻击、傀儡武器、印记血仪来源、同苦触发伤害、噬魂法术位等动态分支会发送明确提示，不自动猜测。
- 破晓血仪自动处理基础光耀附伤；20 尺光照、持握期间黯蚀抗性和不死生物额外骰保留为明确的人工 rider。

### 语义检查

对最终产物逐项检查了：

- 七种血仪的伤害类型、附魔引用、休息期限和单次失血触发。
- 十四种可选血咒及三个子职血咒的三段 Activity、共享次数和防止重复消耗。
- 普通腐蚀血咒不造成 4d6，只有增幅版造成 4d6 暗蚀伤害。

- 所有检查为零 errors；最终结构为 4 个职业侧数据、11 个子职侧数据、42 个可选侧数据、97 个 Activity。
