# Foundry 14／dnd5e 6 生成与 Forge 兼容

- CLI、Web 和 Forge 共用同一生成目标。默认是 Foundry Core 14.370／dnd5e 6.0.6；显式选择 v12 或 v13 仍可生成对应的 dnd5e 4.3.9 数据。新 v14 JSON 使用原生 6 的活动、效果、护甲、移动、感官和资源字段。离线生成不要求启动 Foundry。
- Forge 0.6.0 允许 Core 14.368 起的 14.x 和 dnd5e 6.0.6 起的 6.x。这个版本范围是运行前检查；实际兼容还取决于接口和模块组合。旧 5.3.3 生物包可查看、下载。要在 6.x 采用，使用保留的来源重新生成；没有来源的旧包保持只读，已存在的世界角色不会自动迁移。
- 怪物法术解析器带有相同的原生 6 运行版本准入，同时保留既有旧版配对。离线生成可移植法术清单；实际法术仍需由目标世界的解析器填入。
- Item AI 整理以当前 v14／core 为目标。Species 的默认内容使用 14.370／6.0.6，不能把旧接受账本改标为新目标；显式 14.368 仅用于保留既有 Species 6.0.2 内容身份。
- PDF 生物输入、原语言 Markdown 和候选恢复继续使用现有流程；扫描件没有 OCR。

## 验证范围

已有本地 Foundry 14.370／dnd5e 6.0.6+local.3 的代表证据覆盖 Forge 正常创建、原生与 Midi 命中、重复豁免和重载。仓库里的原生接收回归重放三份未写入世界的合成构造样本。它们不证明所有 Actor、模块组合、未来版本或生产环境通过。PDF 原来的实际浏览器及生成验收有独立的[版本和范围](2026-10-31-forge-pdf-input.md)。

可用 `bun run test:generation`、`bun run test:cli`、`bun run test:forge-cli-web-delivery`、`bun run test:fvtt-json-forge` 与 `bun run smoke:actor:offline` 复查。生成结果仍须按[来源核对说明](../generated-actor-verification.md)与原文对照。

固定版本来源：[Foundry Core 14.370](https://foundryvtt.com/releases/14.370)、[dnd5e 6.0.6](https://github.com/foundryvtt/dnd5e/releases/tag/release-6.0.6)。
