# Chat Memory Guard 人工验收清单

记录测试日期、Foundry/dnd5e/MIDI 版本、浏览器和启用模块清单。任何按钮失效、历史丢失、身份泄露或明显内存回退都按真实缺陷处理。

- [ ] dnd5e 攻击、伤害、豁免按钮在旧卡重新加载后可用。
- [ ] dnd5e 资源消耗与返还符合原卡行为。
- [ ] MIDI Apply Damage、Apply Effects、Undo 与 Concentration 可用。
- [ ] Monk’s TokenBar 及当前实际使用的第三方聊天按钮可用。
- [ ] 向上滚动可以加载旧消息；回到底部后在 1 秒内收敛到配置数量。
- [ ] 世界聊天消息总数和内容没有变化。
- [ ] Token、Actor、系统和隐藏头像切换即时生效。
- [ ] 私聊、盲骰、隐藏内容和无 Actor 权限场景没有通过头像泄露身份。
- [ ] 动画头像在缩略图模式下显示静态首帧或安全默认图，不持续播放高分辨率原图。
- [ ] 连续战斗并切换多个 Scene 后，聊天栏交互仍正常。
- [ ] 记录启用/禁用状态下的 DOM、图片、监听器和 Heap 对照；注明观察时长，不能外推为长期稳定性。
