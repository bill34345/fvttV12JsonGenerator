# 双语描述中的中文 GM 提示重复：诊断与离线修正

用户观察属实。旧版把已经添加中文 GM 提示的整个 Item/活动说明当成“英文原文”，附到中文译文后面，导致同一条中文提示出现两次。Tome Golem 的七能力及对应活动聊天说明共 14 处受到影响。

旧版实际结构是“中文提示 + 中文能力 / 英文原文 / 中文提示 + 英文能力”。本次改为“中文提示 + 中文能力 / 英文原文 / 完整英文能力”。

此前验收只确认英文后半等于生成前的字段，未检查该字段中哪些内容属于作者、哪些内容是程序添加。这项检查不足，旧报告的完整拼接通过不等于英文来源内容都来自作者。

## 修正范围

生成器共用手动能力展示函数，将程序提示与字面规则正文分开。当前事实本地化策略下，只有来源标记有效，且整个展示精确等于对应生成器格式时，英文对照才使用该标记绑定的完整正文；不按中文字符或相似句子删文。作者原文中真实写入的中文、同名提示和链接都保留。缺失或不匹配的来源标记不会用于替换说明。

中文说明与草稿请求身份不变，规则原文、数值、Activity、Effect 和名称不变；旧语言策略不因这项修正改变。审核页同一手动能力的来源展示也使用对应正文。

涉及源码为 `packages/generation/src/actor-text.ts`、`actor.ts`、`reviewed-localization.ts`；没有修改旧冻结包或手工修补最终 Actor JSON。
