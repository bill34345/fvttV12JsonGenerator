# Forge 第一轮单怪物流程优化实测

范围：复用现有能力，缩短单怪物流程、补来源完整性检查、保护关键规则译文。未增加战斗机制、图标种类、第二审核模型或付费审核默认开关；未提交、合并或推送 master。

## 实现与检查

- 唯一完整 statblock 在本地识别，保留完整前言和引用定义。多生物、含糊或不完整来源仍走模型发现。
- 正式 Actor 和来源校验通过、没有配套执行要求时生成无宏包，省略控制配置请求。无宏候选主动点击 AI 审核仍可只审核 Actor；默认不请求。
- IR 校验检查明确能力标题、能力声明的法术等级、引用定义完整落点。后续例外段落和 CRLF 偏移保留；narrative/ignored 标记不能掩盖漏项。检查有限，仍需完整来源人工对照。
- 复用翻译 token 保护，确定性还原明确的再次豁免时点、成功解除、失败差值和“此次伤害致 0 HP”限定，以及已登记的 Saving Throw/Activity 术语。私有传输 token 不改变来源、请求身份或旧批准包；缺失、重复或改变 token 会阻断。没有新增模型请求。
- 实测发现现有技能大小写、Acrobatics 译名和导出 NPC 缺省派生 PB 导致假漂移。只复用既有字段映射和生成器 PB 公式修正校验，没有增加技能或反应机制。

冻结代码后的受影响集成：536 项测试、4441 个断言、38 个文件，全部通过。全仓类型、package 类型、Foundry modules 类型、Forge build、22 来源局部 anti-overfit 通过。架构检查 1306 模块/3082 依赖无违规；后续修改未改变依赖关系。没有执行全仓 CI、生产或长时验收。

## 相同三来源的真实模型对照

旧版模块在本轮修改前冻结于运行中的 Bun 内存；未复制旧模块或新建备份 checkout。最终版冻结后每例独立从原文运行一次，保持原来源 hash，不复用草稿。固定 DeepSeek / deepseek-flash / openai-chat / json_object / reasoning low，中文输出、deferred 审核。调用数为实际 HTTP，包括自动修复及翻译；两版付费 AI 审核请求均为 0。

旧版三例均在更早阶段停止：海妖婆提取 schema 失败、Faldric 技能投影假漂移、小法妖固定能力源绑定编译失败。因此不能把不同终点的总耗时或请求数直接当成完整生成提速。最终版三例的模型发现请求从各 1 次变为 0 次；小法妖走无宏路径，控制配置请求为 0。确定节省了这些步骤，但本批没有证明完整中文流程普遍更快。

“首次正确”定义为本次独立运行在无需人工介入的情况下得到来源、正式生成与中文本地校验全部通过的完整候选。严格按此口径，旧版 0/3，最终版仍 0/3。若再要求首次提取不发生自动修复，结果也仍为 0/3。三例只是样本，不代表一般成功率。来源校验通过、ready_for_gm_review 或 schema 通过不能替代完整中文候选成功。

测量原件在任务 `.local/forge-first-pass-20261011/`：`baseline/`、开发中 `optimized/`、`final/` 与 `comparison.json` 分开保留。没有覆盖初次失败。记录仅保存请求元数据、耗时、数值 usage 和结构化结果，不保存凭据、完整 HTTP 请求/原始响应或推理文本。表中不包含开发调试和续跑；一次早期翻译续接失败未完整落盘 HTTP 计数，该辅助运行不能用于精确总调用数结论。

## 续跑与关键译义

- 小法妖复用同来源 IR，经当前正式流程重验；24 秒/3 次翻译请求得到完整草稿，生成 1 Actor、5 Item、0 Macro。不是新鲜首次成功。个体/集群限制、浴血替换 3d4+2、额外 2d6 力场、GM 选择结束一件同调、1 日一次/30 尺/恢复 15 HP 后变中型集群保留。
- 海妖婆复用同 hash 的已验证 R4 IR/闭合 GM 配置，3 次翻译请求/118 秒后仍有字段被挡。随后仅续失败字段；最后记录完整的 R2 续接为 1 请求/55 秒，86 个 Actor 显示字段身份完整。不是新鲜首次成功，也没有重提取或新增规则模型调用。
- parent 对照能力描述、关键限定及两条引用定义；独立 worker 定点核对再次豁免、目标选择 INT/WIS、5 环胆汁盐水、此次伤害降 0、失败差值和鬼婆债务。最初把海渴症译义也记为通过并不准确：后续浏览器验收发现 keep solid food down 被写成“咽下”，漏掉“不吐出”的意思；parent 对照原文确认此误译，撤回该句的通过结论。没有声称人类已批准全部字段。
- 小法妖的形态切换、浴血替换骰、强制结束同调、治疗与变形继续由 GM 手动处理。文本完整和原生攻击可用不代表这些机制已经自动化。
