# 晶血龙兽 V12：来源、导入与战斗验收

日期：2026-09-09。范围：用户指定的远程 Foundry **12.331 / dnd5e 4.3.9** 世界，仅创建本任务的新角色目录、两个正式生物、测试靶、测试场景、测试战斗与配套宏。地址、凭据和未脱敏日志不写入本报告。

## 来源与正式生成

- 来源核对：[当前面板及用户裁定](2026-09-09-crystalbleed-v12-source-audit.md)。最终输入为 `crystalbleed-drakon-v12-rework.md` 与 `moonstone-salvo-crystal-v12.md`。
- 两个 Actor 均通过 `src/index.ts --fvtt-version 12 --effect-profile modded-v12 --icon-mode off` 正式生成。没有手写或修补输出 Actor JSON。
- 生成器保留明确的 GM 辅助和外部腐化规则标记；它们的执行由配套宏和下述手工边界承担。
- 最后目检发现语言枚举“地底通用语”未被 V12 显示，来源改为标准键 `undercommon` 后正式重生成、原生重导入。三种语言均已读回并在 UI 显示；其他战斗字段不变，最终 40→20 守护计算及 2d8/dazed 重新读回通过。
