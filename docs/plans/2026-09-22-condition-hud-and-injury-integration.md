## 用户目标与范围

Token Action HUD 中自定义状态需要随 Foundry 当前界面语言显示名称和规则描述，中文支持 `cn` / `zh-CN`，英文及未提供翻译的语言回退英文。每种状态使用可区分的原创 SVG，保持 dnd5e 状态的白色剪影、透明背景与小尺寸可读性。伤势采用同样展示方式。

用户已确认纳入旧功能 worktree 的伤势 HP 事件桥接成果；原 worktree 和其混合手册改动保持原样，不整体复制手册。新开发基于已提交 master `e2739f0` 的独立 worktree，不改动主区其他任务的文档。

## 模块职责

- Custom Conditions 提供十九种状态的本地化展示，以及伤势的统一管理入口。既有状态 ID、规则参数、生成器契约保持兼容。
- 伤势模块继续拥有层数、死亡／复活历史与消逝的灵魂仪式，原 Actor flags 仍是唯一长期事实，不迁移或复制到另一份状态。
- Trigger Engine 通过公开事件接口提供 HP 事件；同一伤势事件只能由一种自动化来源处理。仪式联动只提示活动 GM 打开仪式，灵魂意愿、贡献、最终骰和结果仍由 GM 处理。
- 不修改 Token Action HUD、dnd5e 或其他第三方模块源代码，不改变已有战役角色来作测试夹具。
