# Open Session Deck 完整改版计划

状态：已拍板，作为实现、视觉还原与 Foundry E2E 的共同验收规格。

本计划记录完整产品范围。已选定的深色战术控制台视觉稿只决定呈现方式，不能替代或删减下列行为要求。

## 1. 产品目标与布局

- Open Session Deck 是 GM 在战斗中操作队伍与 NPC 的高密度副屏，不是 Actor Sheet 或官方 Combat Tracker 的复制品。
- 主视口为 `1280×800`，左右区域约为 `44 / 56`；`1920` 宽屏增强展示，低于 `960` 时改为“队伍 / 遭遇”分页。
- 基准数据量为 6 名队伍成员、12 名战斗参与者。稳定列、当前行动琥珀色横条和清楚的操作层级优先于装饰。

## 2. 队伍区域

### 2.1 生命值与护甲

- 每张卡同时显示当前 HP、基础最大 HP、最大 HP 修正、有效最大 HP、临时 HP 和 AC。
- 当前 HP 直接编辑，在 Enter 或失焦时提交；降低当前 HP 仍走 dnd5e 原生伤害语义，因此临时 HP 可以吸收伤害。
- 临时 HP 是精确设值，允许降低和清零。
- 最大 HP 使用 dnd5e 的 `tempmax` 相对修正，界面显示 `+N / -N`；有效最大值为基础值加修正。降低后若当前 HP 超出新上限，自动截断，不再二次确认。
- AC 修正由本模块拥有的 Active Effect 写入，不覆盖 Actor 的基础 AC。

### 2.2 角色操作

- 激励按钮根据当前状态显示将发生的动作：`获得激励` 或 `删除激励`。
- 中文界面不出现 `EXH`；显示完整的“力竭”与当前等级，达到上下限时按钮不可用并说明原因。
- 显示死亡豁免成功/失败点，可直接设定点数。
- 提供通用专注切换；结束专注会移除该角色全部专注效果，必须先确认。

### 2.3 状态

- 状态控件为多选列表。已应用状态为选中，未应用状态为未选中。
- 勾选或取消后立即应用/移除，无需第二个“切换状态”按钮。
- 选中、未选中、不可用和处理中不能只靠颜色区分。

### 2.4 批量操作

- 批量操作是独立的聚焦工作区，不在常规卡片上常驻复选框。
- 批量范围只包括 HP 相关操作与状态，不包括激励、力竭、专注、死亡豁免或 AC。
- GM 必须先明确选择目标 Actor。
- 混合状态不被伪装成一致状态；状态批量动作明确分为“全部添加”和“全部移除”。

## 3. 队伍来源

- 用一个世界级 Actor 文件夹设置替代旧的自动发现、固定和隐藏管理模型；不保留第二套竞争来源。
- 所选文件夹的直接 Actor 按 Foundry Actor 目录顺序进入队伍；可选择是否包含子文件夹。
- `character` 与 `npc` 均可成为队伍成员，方便临时同行 NPC 通过拖入/移出文件夹加入或离开。
- Actor 或文件夹移动、创建、删除、重命名后 Deck 实时刷新。
- 设置对所有 GM 共享；保存稳定的文件夹 ID，重命名不能破坏选择。
- 未设置时显示空状态 CTA；已选文件夹被删除时显示明确警告，不静默回退到其他来源。
- 日常 Deck 只保留简洁的“队伍文件夹”入口，不再显示旧的“管理队伍 / 固定 / 隐藏”列表。

## 4. 遭遇区域

### 4.1 队伍成员占位

- 已在左侧队伍中出现的 Actor，在遭遇中仅显示紧凑占位，用于辨认顺序、当前回合和先攻。
- 占位保留直接编辑先攻和“聚焦 Token”靶心按钮；不重复 HP、状态、激励、力竭、Sheet 等队伍操作。

### 4.2 NPC 与遭遇专属角色

- 遭遇区主要用于操作 NPC。dnd5e `npc` 使用完整遭遇卡，并与队伍卡共享直接编辑 HP、最大 HP 修正、临时 HP 和多选状态的交互语义。
- 普通 NPC 默认不显示激励与力竭。
- 遭遇专属的 dnd5e `character` Actor 显示与玩家角色一致的激励和力竭操作。

### 4.3 先攻

- 所有战斗参与者均可直接编辑先攻，保留小数；Enter 或失焦后通过原生 Combat 更新实时同步。
- 可选择 A 与 B，一次逻辑操作交换两者的精确先攻值，包括小数；不得暴露误导性的中间顺序。
- 可单独为 NPC 私密投先攻，也可为所有尚无先攻的 NPC 私密投先攻。
- NPC 投先攻的聊天消息默认为 GM 私密。
- NPC 默认以 `Combatant.hidden` 对玩家隐藏整行；GM 可明确切换为公开。

## 5. 玩家官方 Combat Tracker 的先攻呈现

- 友方定义为：所选队伍文件夹成员，或任何非 GM 用户对其拥有 OWNER 权限的 Actor。
- 敌对单位默认隐藏整行，除非 GM 明确公开。
- 第一轮开始时，未行动友方进入未知先攻队列：显示头像与 `?`，不显示真实先攻，并按名称稳定排列。
- 随回合推进，当前及已经行动的友方锁定到真实位置并显示；第二轮起，第一轮已存在友方的真实顺序公开。
- 第一轮后中途加入的友方，在第一次行动前仍处于未知队列；行动后公开。
- 这是面向普通玩家的 UI 隐藏，不宣称能够对检查客户端文档数据的对抗性玩家保密。

## 6. 视觉与可用性

- 使用选定稿的 Foundry 原生深色战术控制台方向、真实 Actor 图像与 Font Awesome 图标，不制作伪造资产。
- 常用值直接可见、可编辑；次级动作保持紧凑，但任何仅图标按钮都必须有可访问名称与 Foundry tooltip。
- 不可用操作必须保留可见并说明原因；处理中要锁定相关目标，避免重复提交。
- GM 的修改应在成功后立即反映到 Deck；错误必须通知且不得让界面假装已成功。
