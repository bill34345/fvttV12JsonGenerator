# Boss 战提醒 · 浴血攻击强化规格

2026-11-24。桌上行为已由 GM 确认。实施与实测结果见[浴血攻击验收](../acceptance/2026-11-24-boss-reminders-bloodied-attacks.md)。

## 问题

怪物可以把浴血强化直接写在一条攻击的正文里。比如爪击在浴血时命中会使目标倒地，或额外造成 1d6 黯蚀伤害。GM 用这招时容易漏掉附带规则。射程、目标数量等变化也需要在结算之前看见。

## 方案

从原招式的正文识别浴血条款，在选目标或结算攻击时向 GM 显示适用规则。已配置好的 Activity 和效果可沿用原生流程。用当前的原生浴血状态判断强化是否生效，并提供可点击的浴血标记提醒及 GM 手动切换入口。

## 已确认的用户故事

1. 作为 GM，我希望原版资料和自写怪物都能将浴血条款保留在原招式正文里，以便直接把它们带进战斗。
2. 作为 GM，我希望每只怪每场战斗首次进入浴血时能用一张合并提醒看见受影响的招式，以便判断接下来用哪一招。
3. 作为 GM，我希望每次使用受影响的招式时能在对应的卡上看到规则，以便处理当次攻击。
4. 作为 GM，我希望在选目标前看见触及、射程或目标数量的变化，以便选出符合条件的目标。
5. 作为 GM，我希望明确替换的招式使用当前适用的 Activity，可选的招式由我点选，以便复用已有的射程、目标和伤害配置。
6. 作为 GM，我希望附加伤害和命中效果读取结算时的浴血状态，以便处理掷完攻击骰后又掉血或受治疗的情况。
7. 作为 GM，我希望系统有明确命中结果时可以直接使用，缺少结果时能从卡上确认命中的目标，以便多目标攻击也能逐一结算。
8. 作为 GM，我希望特殊 Boss 可以使用 75% 等单独的浴血阈值，以便在设定的阶段改变招式。
9. 作为 GM，我希望能对选中的 Boss 使用「强制浴血」，也能用「恢复自动」交回正常判断，以便处理剧情或特殊机制。
10. 作为 GM，我希望世界关闭自动标记时，怪物重新跌到阈值能够弹出「标记浴血」操作卡，以便直接点卡确认。这种标记在回血过线时自动撤掉。
11. 作为 GM，我希望强化说明、待处理提示和按钮只对 GM 可见，以便决定什么时候让玩家看到怪物能力的实际结果。

## 行为与实现约定

| 场景 | 应有行为 |
| --- | --- |
| 世界开启自动标记 | 由 dnd5e 按当前 HP 和该怪的阈值管理原生标记。默认 50%，允许单只 Boss 使用自定阈值。 |
| 世界关闭自动标记 | Boss 战提醒在需要补标时给活动 GM 弹出私密操作卡。怪物每次从阈值以上降到阈值或以下可操作一次，点「标记浴血」才加标记。同一次低血期间继续掉血不会重复弹。通过这张卡所加的标记在回血超过阈值后自动撤掉。 |
| 剧情需要强制浴血 | 「强制浴血」用独立效果赋予原生浴血状态。GM 点「恢复自动」时移除该效果，并回到世界设置和该怪阈值规定的流程。 |
| 首次进入浴血 | 每只怪每场战斗只显示一次合并的招式变化提醒。关闭自动标记时，再次跨过阈值仍可获取用来补标的操作卡。 |
| 选目标与使用招式 | 在选目标前显示范围和目标等适用变化。明确的替换使用当前适用 Activity。明确的可选版本提供选项。 |
| 确认命中与结算 | 按已确认命中的目标处理。攻击骰后、结算前才进入浴血，仍可应用追加效果。结算前退出浴血，本次不应用追加效果。 |
| 正文与现成配置 | 正文可直接带来可读提醒。已有配置的 Activity 或效果可以点击结算。纯正文条款显示给 GM 裁定。 |
| 可见性 | 强化说明、命中确认与操作按钮只给 GM。实际掷骰与施加状态走 Foundry 原来的可见性。 |

攻击强化读取出手怪物当前的浴血状态。掉血跨线用于发起手动补标或让原生系统更新状态。自动标记、卡片确认和剧情强制分别遵循上表的生效与撤除规则。原生 dnd5e 是主要运行入口，Midi-QOL 为可选兼容。

## 验收

在本地 Foundry Core 14.370／dnd5e 6.1.1 战斗中，从 GM 正常使用招式、选目标和结算的入口验收。检查真实的浴血状态、卡片、所用 Activity、骰子和目标状态。玩家视角核对能看见的内容。用现有的原版怪物验收路线复跑三类浴血提醒。相关记录见[原版怪物验收](../acceptance/2026-11-24-boss-reminders-bloodied.md)。

1. 先验证单只 NPC 的 75% 阈值能正确开关 dnd5e 的原生标记。对照普通 50% 阈值，分别越过和恢复，并验证手动与原生标记同时存在时的行为。
2. 测试世界自动标记开关。在关闭时核对首次及再次跨线的操作卡、点击后的浴血状态、继续掉血时的去重、回血超过阈值后的撤除，以及剧情强制标记直到恢复自动的行为。核对同一怪物每场战斗只出现一次招式变化合并提示。
3. 用单条爪击正文分别测试「浴血时命中使目标倒地」和「浴血时命中额外造成 1d6 黯蚀伤害」。对比浴血与非浴血、命中与未命中，以及攻击骰和结算之间的两种浴血状态变化。
4. 检查预先配好的普通与浴血 Activity。分别验证强制替换、可选版本和只有正文的情况，并确认 GM 在选目标前能看到适用的射程或目标数量。
5. 用两个目标一中一失验证只给实际命中的目标结算。再走一次由 GM 确认命中的路径。核对 GM 私密提示、玩家可见结果及未处理效果的状态。
6. 复跑原版黑布丁分裂、黏土魔像失心狂怒和狂战士浴血狂热。以原样合集和临时测试 Token 检查即时提示、回合开始提醒、持续效果应用与移除。
