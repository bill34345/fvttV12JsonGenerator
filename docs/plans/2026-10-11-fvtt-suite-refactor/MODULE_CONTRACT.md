# 模块子计划共同实施约定

本页是[总计划](PLAN.md)的共享部分，减少每份子计划重复全局规则。它定义实施时如何判断结果，不授权执行任何命令。当前进度只在[执行总账](EXECUTION_LEDGER.md)维护；子计划中的切片是工作定义。

## 开始一个切片

1. 读对应子计划和适用局部 AGENTS；确认该模块真实 owner、已提交基线、worktree/branch、目标输出与已有授权。现有工作树被占用时不接管。
2. 对照精确版本源码/当前支持记录，复核实际问题或改善机会。已有清晰实现无需强行重构；先补真实用户入口、帮助或发布缺口也可以完成一个切片。
3. 选一个用户流程或一个内部状态家族。写清本轮变化、依赖影响、保留身份、最小验证和本轮不做的范围，然后实施。
4. 新外部接口、真实版本变更、迁移或重复失败按既有[开发反馈流程](../../runbooks/development-feedback-loop.md)处理，不以猜测填充通用适配层。

## 一致的交付出口

| 层级 | 应留下的证据 |
| --- | --- |
| 实现 | 本轮差异及唯一 owner；模块未导入其他模块私有实现，browser bundle 无 Node/Bun/运维能力 |
| 机械 | 子计划列出的最小安全入口；构建物、manifest、版本和文件白名单一致；共享接口变化按实际消费者补验证 |
| 来源/业务 | 生成器沿正式来源链；规则输入/输出与原文一致；只在有运行证据时称对应玩法通过 |
| 界面/宿主 | 真正用户入口、宽窄容器、角色权限、关闭/重开/刷新；普通工具结果不代替视觉或客户端接受 |
| 版本 | Core/系统/依赖/候选构建身份明确；5.3.3、6.x 分开，支持声明不由 manifest 区间推断 |
| 手册 | owner 条目、来源、准备、步骤、结果、限制、双语要求和统一手册入口同步；review/build/check 保留覆盖 |
| 恢复/资源 | 先设计最终读回，再结束本轮资源；临时对象、设置和自有服务范围精确，保护其他数据和常驻服务 |
| Git/发行 | 未提交、已提交、已合入、已推送、已发布分别记录；取得对应授权后才进入下一外部动作 |

## 版本与身份

- 开工按[双版本流程](../../runbooks/dnd5e-version-following.md)选精确目标。文中的 6.0.5 来自当前记录，不保证执行时仍是最新稳定。
- 既有 module ID、flags/settings、Compendium/Document UUID、sourceId、IndexedDB/草稿身份、宏/构建绑定不因重构更名。确需数据格式演进时，先保留旧读取、显式迁移与未知字段；没有相应数据写入授权不执行迁移。
- 不创建备份，不直接编辑运行中 LevelDB，不用另一套 Lab 绕开占用。失败时停止对应操作，保留有效证据并报告实际残留。

## 检查选择

子计划列出的命令是现有可选入口，不是每次修改都全跑。执行前用本轮变化说明选择：内部提取用相关契约/类型/行为回归；UI/Hook/版本接口补真实目标链；来源投影补 verifier/语义/anti-overfit；跨模块组合与发布在实际整合边界扩大。

本地开发与检查的 Bun 版本从根 `README.md`“本地开发与检查”核对，命令与子进程沿用该运行时。旧 1.3.8 局部记录保留自己的身份，不提升为当前运行时验证。安全包装入口保留，不手动执行内部 `*:raw`。

同一失败两次无新信息时改变诊断层。报告、导出或清理失败不撤销独立有效行为；来源/接口/目标未改变的证据按绑定复用。没有本模块公共 adapter 时，先用现有安全入口或最小模块自有检查，不把建设测试平台作为每项重构的前置。

## Chrome 与环境占用

按当前 Chrome 执行技能和用户已选 GPT-6.1 Sol / medium 执行角色处理；复用已授权、适合本批次的执行聊天和会话。派发、权限核实、回传和结束父回合遵守现有协议，不为每个子案例创建新聊天。工具/URL 安全拒绝不能通过换通道、托管或重打包绕过。

Forge 正在使用的 5.3.3 Mirror 不是本计划的空闲资源。本轮规划没有任何 Foundry 操作；后续只有明确 owner/窗口与当时授权满足后，才安排实机接受。长时验收仅在用户要求相应范围时运行。

## 一个模块完成后

在总账记录本轮已接受范围、原始证据入口、未接受层级、手册/构建身份、Git 状态和唯一下一步。架构负责人审阅语义/图片/原件，不把 worker 报告当作全部接受。若后续只改其他模块或报告，不重开已闭合的行为。
