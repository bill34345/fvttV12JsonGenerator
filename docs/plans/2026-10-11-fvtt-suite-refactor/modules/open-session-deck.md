## 目标与当前事实

保持 GM 的队伍/遭遇面板与同会话副屏可独立使用，把它作为统一帮助、清晰生命周期和版本适配的第一个完整试点。已有合理的 controller/store/adapter 不为重构而重写。

- owner：[foundry-modules/open-session-deck/](../../../../foundry-modules/open-session-deck/)。
- 稳定 runtime ID：`open-session-deck`；默认阶段：P2。
- 既有版本0.1.1，当前候选0.2.0；manifest跨14.364–14.368 / 5.3.3–6.0.6，运行门仍是精确组合。新增6.0.6只有静态候选；Next的历史业务接受仅力竭3→4→3与重载，本批帮助/呈现/提示接受另记，不推广到全部命令或完整GM/玩家矩阵。没有模块硬依赖。
- 关键归属：`src/controller.ts`、`src/store.ts`、`src/dnd5e-adapter.ts`、`src/surfaces.ts`、`src/index.ts`。
- 版本与接受须继续对照[支持矩阵](../../../acceptance/current-support-matrix.md)，上述记录不保证未来执行时仍是最新目标。

## 切片

### D1 帮助与能力呈现

迁入本模块用户说明，接通可选合集帮助并保留独立帮助；把当前目标版本/命令不可用原因呈现清楚，不增加新的世界写入。

本批已把唯一可编辑说明迁入`docs/manual.json`，中央目录仅留source指针；面板与同会话副屏共用“帮助”入口，公开`openHelp()`保持GM权限。合集启用且帮助ABI1匹配时定位稳定条目`open-session-deck`，缺失/停用/接口不匹配或打开失败时使用本模块只读后备窗口。后备保留单实例、最小化恢复和置前。现有`openPanel/openPopout`会保存`lastOpenMode`，验收准备期记录并在收尾恢复；帮助本身不得写设置或文档。

源码已增加真实Core/dnd5e配对和支持态，直接编辑输入及父标签复用已有command capability的不可用原因；不放宽精确支持版本门。面板及同会话副屏实际14.368/6.0.5呈现已接受；本次没有禁用输入，原因提示仅有局部测试，真实不可用UI仍NOT_EXECUTED。

### D2 命令与界面生命周期

核对 controller 与 adapter 的 Interface；面板/副屏共享命令语义，执行前重新解析目标 UUID。只提取实际混合职责，关闭/重开不重复订阅。

源码已为工具栏、辅助、快捷键/Token入口和关闭路径加入共同异步失败提示，动作仍在点击调用栈立即执行以保持popout手势。取消、busy及已有业务错误处理保持现状；最终76项/529断言和独立审阅见总账。真实工具栏点击的受控设置拒绝已通过原生通知的实时DOM/样式/位置读回；原晚读未捕获提示的失败保留，截图未拍到通知，不作为可见证据。其余业务命令在D3接受。

### D3 版本与副屏接受

沿系统 adapter 明确各目标的原生 HP、状态和力竭出口；保持既有 6.0.5 原生效果 ID 路径，按变更补面板与同会话副屏代表链。

## 必须保护

现有 Actor/Combat/Token 身份、用户队伍来源设置、GM 权限和原生命令；副屏不创建第二个 Foundry 客户端、Canvas 或 socket。

## 本模块最小真实接受

- 合集停用仍能打开 Deck 和本模块帮助；只读打开/重开不写 Actor 或 Combat。
- 同一目标的 HP/力竭代表命令按系统原生方法读回；失效 UUID、非 GM、重复点击得到明确结果。
- 窄容器与副屏正常；只结束本轮自有副屏/fixture，既有队伍、回合和设置恢复。
