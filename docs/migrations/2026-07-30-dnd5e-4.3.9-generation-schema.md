# dnd5e 4.3.9 Actor / Item 生成结构迁移

本迁移适用于 Foundry v12/v13、dnd5e 4.3.9 目标。生成器不提供 legacy 与规范字段的双写模式。

## 移除的 legacy 字段

- Item `system.activation`
- Item 或 Activity `uses.value`
- Item 或 Activity `uses.per`

## 规范结构

- activation 由 `system.activities.<stable-id>.activation` 持有。
- uses 使用 `spent`、`max`、`recovery`。
- Activity map key 与 Activity `_id` 相同，均为基于来源逻辑路径生成的稳定 16 字符 ID。
- source Item 分类先经过规范映射再得到 Foundry 文档类型，例如 `armor → equipment`、`staff → weapon`。

已有消费者若读取 Item-level activation，应迁移到对应 Activity；若按 `value/per` 计算剩余次数，应改为 `max - spent` 并读取 `recovery`。验证器会拒绝继续携带上述 legacy 字段的生成结果。

本迁移只声明锁定 dnd5e 4.3.9 来源的结构兼容。除非另有该精确产物的导入、DataModel、行为和导出回读证据，否则不得据此声明 Foundry v12/v13 运行时 Pass。
